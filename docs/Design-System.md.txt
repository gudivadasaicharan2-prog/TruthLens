TruthLens Design System v1.0
A premium dark-futuristic design language for AI forensics products

1. Brand Foundation
Product: TruthLens — AI Image Detection Platform Aesthetic: Dark futuristic · Glassmorphism · Cybersecurity · AI SaaS Inspiration: OpenAI · Linear · Perplexity · Adobe Firefly · Vercel · Apple Mode: Dark-only (color-scheme: dark)

8. Glassmorphism
Two authoritative utilities — do not create ad-hoc variants.

8.1 .glass — Standard
background: color-mix(in oklab, var(--card) 55%, transparent);
backdrop-filter: blur(20px) saturate(140%);
border: 1px solid oklch(1 0 0 / 0.08);
box-shadow: var(--shadow-glass);
Use for: sidebars, secondary cards, feed items.

8.2 .glass-strong — Elevated
background: color-mix(in oklab, var(--card) 75%, transparent);
backdrop-filter: blur(28px) saturate(160%);
border: 1px solid oklch(1 0 0 / 0.12);
box-shadow: var(--shadow-glass);
Use for: navbar, modals, overlays, hero panels, KPI cards.

Never hand-write -webkit-backdrop-filter — Lightning CSS drops the standard property in production.

9. Motion
Powered by Framer Motion. Reduced-motion should be respected via prefers-reduced-motion.

9.1 Durations
Speed	Duration	Use
Instant	150ms	Color/opacity hover
Fast	200–250ms	Scale, tabs, small transitions
Base	300–400ms	Page enter, card reveal
Medium	600ms	Section stagger, KPI counters
Slow	1.6s	Gauge fill
Ambient	6s–32s	Background blobs, rotating rings
9.2 Easing
Curve	Use
easeOut	Enters, reveals (default)
easeInOut	Loops (blobs, particles, pulses)
linear	Rotating rings
spring { stiffness: 400, damping: 30 }	Active nav indicator (layoutId)
9.3 Signature Animations
Name	Pattern
Page enter	initial={{opacity:0,y:8}} animate={{opacity:1,y:0}} duration:0.4
Card stagger	children delay i * 0.05–0.1
Hover lift	hover:scale-[1.02] or translate-y-[-2px]
Gauge fill	animate(progress, target, {duration: 1.6, ease: "easeOut"})
Ambient blob	x/y: [0, ±100, 0], duration 24–32s, infinite, easeInOut
Pulse tile	scale: [1, 1.08, 1], 1.8s, infinite

18. Accessibility
Contrast: all text ≥ WCAG AA on dark background
Focus rings: always visible via focus-visible:ring-2 ring-ring
Motion: respect prefers-reduced-motion (disable ambient blobs, gauge fills instantly)
Semantic HTML: <main>, <nav>, <header>, <section> with headings
ARIA on live regions (aria-live="polite" on scan overlay, gauges)
