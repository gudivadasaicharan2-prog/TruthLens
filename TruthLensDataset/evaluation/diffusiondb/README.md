# DiffusionDB Dataset

## Dataset Name
DiffusionDB

## Purpose
Evaluation dataset for AI-generated image detection. Contains images generated by diffusion models (Stable Diffusion, DALL-E, etc.).

## Expected Folder Structure
```
TruthLensDataset/evaluation/diffusiondb/
└── ai/
    ├── [AI-generated images]
    └── ...
```

## Supported Image Formats
- jpg
- jpeg
- png
- bmp
- webp

## Download Status
Pending

## Notes
This dataset will be used to evaluate the model's ability to detect images generated by diffusion-based AI models.
