# COCO Dataset

## Dataset Name
COCO (Common Objects in Context)

## Purpose
Evaluation dataset for real image detection. Contains real photographs from the COCO dataset.

## Expected Folder Structure
```
TruthLensDataset/evaluation/coco/
└── real/
    ├── [real photographs]
    └── ...
```

## Supported Image Formats
- jpg
- jpeg
- png
- bmp
- webp

Pending
