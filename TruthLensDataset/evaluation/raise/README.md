# RAISE Dataset

## Dataset Name
RAISE (Raw Image Archive for Scientific Image Evaluation)

## Purpose
Evaluation dataset for real image detection. Contains high-quality real photographs with RAW format origins.

## Expected Folder Structure
```
TruthLensDataset/evaluation/raise/
└── real/
    ├── [real photographs]
    └── ...
```

## Supported Image Formats
- jpg
- jpeg
- png
- bmp
- webp

## Download Status
Pending

## Notes
This dataset will be used to evaluate the model's ability to correctly identify high-quality real photographs.
