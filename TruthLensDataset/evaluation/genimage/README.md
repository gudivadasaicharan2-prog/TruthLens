# GenImage Dataset

## Dataset Name
GenImage

## Purpose
Evaluation dataset for AI-generated image detection. Contains images generated by various generative AI models.

## Expected Folder Structure
```
TruthLensDataset/evaluation/genimage/
└── ai/
    ├── [AI-generated images]
    └── ...
```

## Supported Image Formats
- jpg
- jpeg
- png
- bmp
- webp

## Download Status
Pending

## Notes
This dataset will be used to evaluate the model's ability to detect AI-generated images from various generative models.
